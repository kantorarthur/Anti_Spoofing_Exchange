# Anti Spoofing Exchange

### Context:
I was so fascinated when I first heard about Spoofing and Low Latency Arbitrage in trading. When I first heard about it I thought it was the most insane and also the coolest thing I've ever heard, and that's when I decided that my goal it's to work in Fintech, especially in HFT. 

So I'm building an "Anti Spoofing Exchange", trying to use my limited knowledge about spoofing **(which is illegal, honorable to mention)** for a good cause.<br><br> I'm also trying to get the lowest latency using my knowledge of C++, (maybe) x86 Assembly, Cache/Hardware Optimizations, Networking Protocols, Computers Architecture and so on.

**Explained in simplest terms: Spoofing happens when trader X places a "fake order" which lasts for very little time, without the intent of being completed (the order). That trader is doing that so he can manipulate the markets in his favour using the algorithmic trading tools of other big trading firms.**
